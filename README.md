# FrameShift

FrameShift is a dark, instrument-like single-page studio for animating a still, recasting a performer, marking a local video in 15-second pieces, and previewing a camera feed. The recast workflow supports any cast presentation, and its direction field offers contextual prompt suggestions while the user writes.

The production-ready static site lives in `dist/` and has no build step. Open `dist/index.html` through a local web server to use file handling, IndexedDB media persistence, installability, audio recording, camera preview, and opt-in completion notifications. Hosted video and image generation are intentionally represented by honest connection errors until a model backend is attached.

Live app: https://frameshift-studio.trueyew12.chatgpt.site/
